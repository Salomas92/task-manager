## Descrição

Esse projeto está sendo construído com Node.js puro, a ideia é entender os fundamentos antes de avançar para bibliotecas e frameworks. Estou fazendo um gerenciador de tarefas para treinar algorítimo e estrutura de dados com as ferramentas nativa do node.
É um projeto simples para iniciantes que não quer pular etapas.
